# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/omegaatt36/noccounting/security/advisories/new).
Do not open a public issue.

Include the affected version, steps to reproduce, and the impact you observed.
Reports involving the Telegram bot token, LLM API keys, or other credentials handled by noccounting are especially welcome.
